# A Weather App
Simple weather app created by me! Fully coded in HTML, JS, and CSS. Added the basic weather necessities like the Fahrenheit, Celsius, wind, humidity, air quality, precipitation, states, cities, and etc. 
On the bottom on the main screen it will show all the states plus the cities underneath.
When clicking on your state that you live in it will pop up with the state itself the Fahrenheit or Celsius whatever you prefer, the background will show the different colors;

Sunny = yellow
Rainy = Blue
Cloudy = Gray
Snowy = Whiteish

It will also show the specific on what to wear, and the next three days of weather. A search bar is also there to type in your state or the abbrevation of your own state.
